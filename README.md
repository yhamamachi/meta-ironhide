# OpenEmbedded/Yocto BSP layer for Ironhide

This layer provides support for Ironhide (R-Car X5H, r8a78000) for use with OpenEmbedded and/or Yocto.

## Original BSP image

* core-image-minimal

## Layer Dependencies

This layer depends on:

* poky

```bash
    URI: git://git.yoctoproject.org/poky
    layers: meta, meta-poky, meta-yocto-bsp
    branch: scarthgap
```

* meta-openembedded

```bash
    URI: git://git.openembedded.org/meta-openembedded
    layers: meta-oe, meta-python, meta-networking, meta-multimedia
    branch: scarthgap
```

* meta-arm

```bash
    URI: git://git.yoctoproject.org/meta-arm
    layers: meta-arm-toolchain
    branch: scarthgap
```

# Build Instructions

## Required Environment

* Refer to https://docs.yoctoproject.org/brief-yoctoprojectqs/index.html to prepare Build Host.

* This also needs git user name and email defined:

```bash
   $ git config --global user.email "you@example.com"
   $ git config --global user.name "Your Name"
```

## Build using build script

```bash
git clone <URL of this repository>
cd meta-ironhide
./build.sh
```

Build options can be confirmed by -h option:

```bash
./build.sh -h
```

The build script clones poky, meta-openembedded and meta-arm under `build/`,
and runs the build in `build/build-ironhide`.

Build artifacts can be found in `build/build-ironhide/tmp/deploy/images/ironhide/`.

## Build Instructions for SDK

```bash
./build.sh --sdk
```

The SDK can be found in the output directory `tmp/deploy/sdk`

* `poky-glibc-x86_64-core-image-<image type>-aarch64-<machine name>-toolchain-x.x.sh`

# Boot Instructions

Overall flow:

1. Flash U-Boot on CM33 to the board using `ipl-burning`
2. Copy the build artifacts to the TFTP server
3. Configure the network (TFTP) on U-Boot on CM33
4. Run the boot command to start U-Boot on CA720
5. Boot Linux from U-Boot on CA720

## 1. Flash U-Boot on CM33

`ipl-burning` is generated in the deploy directory (`ipl-burning/`).
It contains `burn.py`, `run.sh` (Linux), `run.bat` (Windows), and the U-Boot on CM33 images.

```bash
cd build/build-ironhide/tmp/deploy/images/ironhide/ipl-burning
./run.sh
```

`run.sh` installs `pyserial`, `colorama` and `tqdm` with `pip3`, then runs `burn.py`.
Follow the instructions printed by the script:

* Before flashing: power off the board, set DIP-SW (SW43) to `1110 0000`
  (switches 1-3 ON, others OFF), connect the board to the PC via USB, then power on.
* After flashing: power off the board and set SW43 to `0100 0000` (only switch 2 ON).
  The board then boots from the flashed U-Boot on CM33.

The following images are written to HyperFlash:

| Address      | File                            |
| ------------ | ------------------------------- |
| `0x34000000` | `u-boot-elf-cm33-ironhide.shdr` |
| `0x34040000` | `u-boot-elf-cm33-ironhide.srec` |

## 2. Prepare TFTP server

Create the `x5h_wb/` directory in the TFTP root directory, and copy the required files
(`.bin`, `.srec`, `.gz`, etc.) from `build/build-ironhide/tmp/deploy/images/ironhide/`.

The default environment of U-Boot on CM33 (`recipes-bsp/u-boot/u-boot-cm33/ironhide.env`)
refers to the following files:

| File                                                                    | Usage                                          |
| ----------------------------------------------------------------------- | ---------------------------------------------- |
| `rcar5-bl2.bin`                                                         | SCP firmware (written to UFS)                  |
| `bl31-ironhide.bin`                                                     | TF-A BL31 (written to UFS)                     |
| `apu-tee-ironhide.bin`                                                  | OP-TEE (written to UFS)                        |
| `u-boot-ironhide.bin`                                                   | U-Boot on CA720 (written to UFS)               |
| `zephyr.bin`                                                            | CR52 image (not generated by this layer)       |
| `u-boot-elf-cm33-ironhide.bin`, `u-boot-elf-cm33-ironhide-header.bin`   | Update U-Boot on CM33                          |
| `Image-ironhide.bin`                                                    | Linux kernel                                   |
| `r8a78000-ironhide.dtb`                                                 | Device tree                                    |

Note: `_load_linux` in `ironhide.env` loads `x5h_wb/r8a780000-ironhide.dtb`, while the build
generates `r8a78000-ironhide.dtb`. Rename the file or fix the environment variable.

## 3. Configure TFTP on U-Boot on CM33

On the U-Boot on CM33 console, set the IP addresses (adjust to your environment):

```
=> setenv ipaddr <board ip>
=> setenv serverip <tftp server ip>
```

To write the IPL images to UFS via TFTP:

```
=> run flash_ipls
```

`flash_ipls` loads `rcar5-bl2.bin`, `bl31-ironhide.bin`, `apu-tee-ironhide.bin` and
`u-boot-ironhide.bin` via TFTP and writes them to UFS.

## 4. Start U-Boot on CA720

Run the boot command defined in the default environment:

```
=> run boot_ca0
```

`boot_ca0` starts SCP, loads TF-A / OP-TEE / U-Boot from UFS and starts CA720.
U-Boot on CA720 is up when its prompt is shown.

## 5. Boot Linux

Load the kernel, device tree and rootfs from U-Boot on CA720, then boot.

**Note: `maxcpus=1` is currently required in the kernel command line.**
Without it, the Linux kernel does not boot.
